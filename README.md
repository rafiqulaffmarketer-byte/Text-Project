# Text-Project

A Next.js + TypeScript project. It is still early: the app has not been scaffolded yet.

## Tech stack

- Node.js 18+
- TypeScript
- Next.js (App Router)
- React (`.tsx`)
- npm

## Requirements

- Node.js 18 or newer

## Setup

```bash
npm install
```

After the Next.js app exists:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
